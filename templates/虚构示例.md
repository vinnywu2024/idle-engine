# 虚构示例（演示如何填写）

> 以下条目均为**虚构**，仅用于演示字段如何填写，不对应任何真实人物或事项。

## 示例一：碎片时间、自己做

| 字段 | 内容 |
|---|---|
| 事项 | 整理书桌抽屉 |
| 领域 | 家 |
| 时长 | 5分钟 |
| 精力 | 低 |
| 场景 | 在家、任何 |
| 价值 | 中 |
| 状态 | active |
| 条目类型 | 想做事项 |
| 备注 | 顺手把笔和票据分类 |

## 示例二：整块时间、需要专注

| 字段 | 内容 |
|---|---|
| 事项 | 学习一个新的命令行工具并写笔记 |
| 领域 | 兴趣 |
| 时长 | 2小时+ |
| 精力 | 高 |
| 场景 | 电脑前 |
| 价值 | 高 |
| 状态 | active |
| 兴奋点 | 懂原理、要成品 |
| 条目类型 | 想做事项 |
| 备注 | 属于「跑通」类，走通后标 done，后续打磨另起一条 |

## 示例三：触发式采购清单

| 字段 | 内容 |
|---|---|
| 事项 | 书店采购：笔记本、书签 |
| 领域 | 家 |
| 时长 | 5分钟 |
| 精力 | 低 |
| 场景 | 外出 |
| 地点 | 书店 |
| 价值 | 中 |
| 状态 | 触发 |
| 条目类型 | 想做事项 |
| 备注 | 到书店才调出，不参与「闲了」；不代勾 |

## 示例四：工作提醒指针（只读）

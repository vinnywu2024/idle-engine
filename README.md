# Idle Engine · 闲时引擎

> 一套个人闲时任务管理系统：随时口述「想做的事」，当你说「闲了」的时候，获得 1–3 件与当下情境匹配的推荐。
> A personal idle-time task management system. Capture things you want to do, and get 1–3 context-matched suggestions whenever you say "I'm free."

---

## 它解决什么问题

一个很具体的困扰：**突然闲下来的时候，想不起自己该做什么，于是那段时间就被短视频吃掉了。**

这不是记忆力问题，而是**启动成本**问题。普通待办清单要求你先打开清单、扫一遍、挑一件、说服自己开始——这一整套成本，比「打开短视频」高。所以在每个犹豫的瞬间，短视频赢了。

闲时引擎的唯一目标：**把「我此刻该做什么」这个答案的获取成本，压到比打开短视频更低。**

它不与短视频争夺意志力，而是绕开意志力，直接把答案递到手边。

## 它不是待办清单，而是「想做池」

- 待办清单装的是别人催、有 deadline 的事——那些交给日历和提醒就够了。
- 想做池装的是：**有价值、但没人催、没有 deadline，于是一直压着、最后忘了的事。**

### 三条核心原则

1. **采集摩擦必须极低**——摩擦是这类系统的第一号死因，说一句话就应能录入，不追问。
2. **信息只增不删**——做完标 `done`、不想做标 `放弃`，条目本身永远保留，以支持长期回看与分析。
3. **检索不做减法**——场景不做排除式筛选，避免「该出现的事没出现」。

## 快速开始

> 👤 **如果你是第一次使用（给人看）**：不用自己动手，先打开 [小白上手指南.pdf](小白上手指南.pdf)，按截图复制开场白、在豆包「工作任务」里发送，让 AI 自动帮你建好。
>
> 下面的 1–5 步是**给 AI Agent 的执行清单**，供 Agent 按序搭建；你也可以直接把本仓库链接发给豆包，它会读取并执行这些步骤。

1. 选一个支持多视图、富字段类型的表格工具（如飞书多维表格 / Airtable / 任意多维表格），按 [`docs/02-数据结构与字段.md`](docs/02-数据结构与字段.md) 建一张「想做池」。
2. 日常随时口述想做的事，按 [`docs/03-运行机制.md`](docs/03-运行机制.md) 的录入规则低摩擦入库。
3. 闲下来时说「闲了」（可带时长/精力/场景参数），获得 1–3 件推荐。
4. 每周做一次周回顾，保持池子健康。
5. 如果你还需要把「工作任务」与「个人想做」分开管理，见 [`docs/04-工作库衔接.md`](docs/04-工作库衔接.md)。

> 也可以直接使用 [`templates/`](templates/) 里的空白模板和虚构示例快速上手。

## 边界（它不做什么）

- 不管理有明确 deadline 的事——那是日历/提醒的职责。
- 不按领域分桶存储，领域只作筛选标签。
- 不替你做决定，只给建议和理由；不代勾采购清单。
- 不删除条目（误录除外）。
